`<jimble-select>` は、選択肢から 1 つ選ぶ入力です（WAI-ARIA の collapsible dropdown listbox パターン）。選択肢は `jimble-option` で書きます。フォームに参加し、選ばれた値を送信します。

## 注意

- ラベルは [Field](../field/) で付けます。ボタンの名前は「ラベル + 現在の値」として読み上げられます。
- 未選択のときは `placeholder`（なければ「選択してください」）が表示されます。ネイティブの `<select>` と違い、最初の選択肢が自動で選ばれることはありません。
- 選択肢の絞り込み（コンボボックス）と複数選択は未対応です。

## キーボード操作

| キー               | 動作                                                                                     |
| ------------------ | ---------------------------------------------------------------------------------------- |
| Enter / Space / ↓  | （ボタンで）開いて、選択中（なければ最初）の選択肢へ                                     |
| ↑                  | （ボタンで）開いて最後の選択肢へ                                                         |
| 文字               | （閉じているとき）その文字で始まる選択肢に値が変わる。（開いているとき）その選択肢へ移動 |
| ↓ / ↑ / Home / End | 選択肢の移動（無効は飛ばす。端で止まる）                                                 |
| Enter / Space      | 選択して閉じる                                                                           |
| Esc                | 選択を変えずに閉じる                                                                     |
| Tab                | 選択を変えずに閉じて、次の要素へ進む                                                     |
