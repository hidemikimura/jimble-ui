`<jimble-combobox>` は、文字を入力して候補を絞り込み、選択肢から 1 つ選ぶ入力です（WAI-ARIA の combobox・list autocomplete パターン）。選択肢は [Select](../select/) と同じ `jimble-option` で書きます。フォームに参加し、選ばれた値を送信します。

## Select との使い分け

| 状況                              | 使うもの             |
| --------------------------------- | -------------------- |
| 選択肢が少ない（目安: 10 個ほど） | [Select](../select/) |
| 選択肢が多く、探して選ぶ          | Combobox             |
| 自由な文字を入力させる            | [Input](../input/)   |

## 注意

- **自由入力は値になりません。** 選択肢に無い文字を入れて離れると、選択中の表示に戻ります。
- 一致は、全角・半角、大文字・小文字、ひらがな・カタカナ、空白を区別しません。`jimble-option` の `keywords` に読み（`とうきょう tokyo`）を書くと、それでも一致します。
- 一致のさせ方は `match`（`contains` = 含む・既定、`starts-with` = 前方一致）。独自の規則は、`filter` プロパティに `(query, option) => boolean` を渡します。
- サーバー側で絞るときは、`jimble-search`（`detail.query`）を受けて、`jimble-option` を差し替えます。追加・削除・文字の変更に追従します。
- 入力すると先頭の候補が選ばれた状態になり、Enter でそのまま決められます。値が変わるのは、Enter・クリックで選んだときだけです。
- 候補の件数と「一致する選択肢がありません」は、読み上げにも伝わります。
- 入力中の候補は、入力欄にフォーカスが残ったまま操作します（`aria-activedescendant`）。
- 複数選択・新しい項目の作成（タグ入力）は未対応です。
- 選択を解除できるようにするには `clearable` を付けます。

## キーボード操作

| キー  | 動作                                                                                     |
| ----- | ---------------------------------------------------------------------------------------- |
| 文字  | 候補を絞って開く（変換中は絞り込みだけ。Enter・矢印は変換を優先する）                    |
| ↓ / ↑ | （閉じているとき）全候補を開く。（開いているとき）候補の移動（無効は飛ばす。端で止まる） |
| Enter | （開いているとき）候補を選んで閉じる。（閉じているとき）フォームを送信                   |
| Esc   | 選択を変えずに閉じて、入力欄を選択中の表示に戻す                                         |
| Tab   | 選択を変えずに閉じて、次の要素へ進む                                                     |
