`<jimble-combobox>` は、文字を入力して候補を絞り込み、選択肢から 1 つ選ぶ入力です（WAI-ARIA の combobox・list autocomplete パターン）。選択肢は [Select](../select/) と同じ `jimble-option` で書きます。フォームに参加し、選ばれた値を送信します。

### 入力から候補を取得する（`load`）

`load` プロパティに関数を渡すと、入力した文字からその関数で候補を取得して表示します。サーバーへの問い合わせ（`fetch`）も、ブラウザ内のデータの検索も、同じ書き方です。

::example combobox/load

- 関数は `(query, signal) => 項目の配列（または Promise）` です。項目は `{ value, label, keywords?, disabled? }`。
- 入力が止まってから呼ばれます（`load-delay`、既定 250 ms）。**古い検索の結果は捨てられ**、`signal`（`AbortSignal`）で中止されます。`fetch` に渡すと通信も止まります。
- 返した項目がそのまま表示されます（部品側では絞り込みません）。取得中は「読み込み中」、失敗すると「候補を読み込めませんでした」と表示され、`jimble-load-error`（`detail.error`）が出ます。
- `load-min-length` で、入力が何文字以上になってから呼ぶかを指定できます（既定 0。候補を開いただけで、空の検索語で呼ばれます）。
- 選択済みの項目の表示は、値だけでは分かりません。`value` を初期値にするときは、`items` プロパティに `[{ value, label }]` を渡すと、その表示が使われます（渡さなければ値がそのまま表示されます）。

### 複数選択（`multiple`）

::example combobox/multiple

- 選んだ項目はチップで並び、同じ `name` で複数の値が送信されます（`FormData.getAll('pref')`）。開いたままで続けて選べ、もう一度選ぶと解除されます。
- 初期値は `value` 属性にカンマ区切り（`value="tokyo,osaka"`）で書きます。カンマを含む値は `values` プロパティ（配列）で渡してください。`values` は現在の選択の配列です。
- 空の入力で Backspace を押すと、最後の項目を外せます。チップの × でも外せます。選択・解除は読み上げにも伝わります。

### 一覧にない値の追加（`creatable`）

::example combobox/creatable

- 入力に一致する項目が無いとき、末尾に「「○○」を追加」が出ます。Enter やクリックで、その文字が値と表示の項目になります。`jimble-create`（`detail` は追加した項目）が出るので、必要ならサーバーに登録してください。
- `create` プロパティに `(text) => 項目 | Promise<項目 | null>` を渡すと、項目の作り方（登録して ID を受け取るなど）を決められます。`null` を返すと追加しません。
- `multiple` と組み合わせるとタグ入力になります。`load` とも組み合わせられます。
- 追加した項目は、この部品の中に覚えられます（`jimble-option` は増えません）。保存はアプリの仕事です。

### 選択数の上限（`max-items`）

::example combobox/limit-reorder

- 複数選択で、選べる数の上限を指定します。上限に達すると、未選択の候補は選べなくなり（`aria-disabled`）、矢印キーも飛ばします。選ぼうとすると「最大 n 件まで選べます」が読み上げられます。選択済みを外せば、また選べます。
- `values` プロパティで上限を超える数を入れることはできますが、検証は行いません。

### チップの並べ替え（`reorderable`）

上の例のとおり、`reorderable` を付けると、選んだ項目（チップ）の順番を変えられます。送信される値の順番も、入れ替えた順になります。

- **キーボード**: 入力欄が空のとき ← でチップへ移り、← → でチップ間を移動、**Alt + ← →** で入れ替え、**Alt + Home / End** で先頭・末尾へ、Delete で削除、Esc（または Enter・↓）で入力欄に戻ります。入れ替えた結果は「「○○」を n 件中 m 番目に移動しました」と読み上げられます。
- **マウス**: チップをドラッグします（挿入位置が線で示されます）。
- **タップ・ポインター 1 本**: チップをタップ（クリック）してフォーカスすると、「前へ」「後ろへ」ボタンが出ます（WCAG 2.5.7 のドラッグに代わる操作）。ボタンは端では押せなくなります。
- 並べ替えると `jimble-reorder`（`detail.values` に新しい順の値）と `change` が出ます。
- `reorderable` でなくても、チップにはフォーカスでき、Delete で削除できます。

### 候補のグループ分け（`group`）

::example combobox/groups

- `jimble-option` の `group` 属性（`load` や `items` の項目では `group` プロパティ）に同じ名前を付けると、見出し付きでまとまります。離れて書いても、最初に現れた位置に集まります。`group` のない候補は、そのままの位置に並びます。
- 絞り込むと、一致する候補がないグループの見出しは消えます。**既定ではグループ名は絞り込みの対象外です。** `search-group` を付けると、グループ名でも絞り込めます（「関東」と入力すると、そのグループの候補がすべて残ります。読み・全角半角などの扱いは候補の文字と同じです）。
- `jimble-select` では `group` は使われません。

## Select との使い分け

| 状況                              | 使うもの             |
| --------------------------------- | -------------------- |
| 選択肢が少ない（目安: 10 個ほど） | [Select](../select/) |
| 選択肢が多く、探して選ぶ          | Combobox             |
| 自由な文字を入力させる            | [Input](../input/)   |

## 注意

- **既定では自由入力は値になりません。** 選択肢に無い文字を入れて離れると、選択中の表示に戻ります。値にしたいときは `creatable` を付けます。
- 一致は、全角・半角、大文字・小文字、ひらがな・カタカナ、空白を区別しません。`jimble-option` の `keywords` に読み（`とうきょう tokyo`）を書くと、それでも一致します。
- 一致のさせ方は `match`（`contains` = 含む・既定、`starts-with` = 前方一致）。独自の規則は、`filter` プロパティに `(query, option) => boolean` を渡します。
- 検索語の変化は `jimble-search`（`detail.query`）でも分かります。`load` を使わず、`jimble-option` を自分で差し替える方法もあります（追加・削除・文字の変更に追従します）。
- 入力すると先頭の候補が選ばれた状態になり、Enter でそのまま決められます。値が変わるのは、Enter・クリックで選んだときだけです。
- 候補の件数と「一致する選択肢がありません」は、読み上げにも伝わります。
- 入力中の候補は、入力欄にフォーカスが残ったまま操作します（`aria-activedescendant`）。
- タッチ操作でのドラッグ並べ替えは未対応です（タップで出る「前へ / 後ろへ」ボタン、またはキーボードで並べ替えられます）。
- 選択を解除できるようにするには `clearable` を付けます。

## キーボード操作

| キー  | 動作                                                                                     |
| ----- | ---------------------------------------------------------------------------------------- |
| 文字  | 候補を絞って開く（変換中は絞り込みだけ。Enter・矢印は変換を優先する）                    |
| ↓ / ↑ | （閉じているとき）全候補を開く。（開いているとき）候補の移動（無効は飛ばす。端で止まる） |
| Enter | （開いているとき）候補を選んで閉じる。（閉じているとき）フォームを送信                   |
| Esc   | 選択を変えずに閉じて、入力欄を選択中の表示に戻す                                         |
| Tab   | 選択を変えずに閉じて、次の要素へ進む                                                     |
