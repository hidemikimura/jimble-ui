`<jimble-dual-listbox>` は、左に未選択の項目、右に選択済みの項目を並べ、「追加」「削除」で移す選択です。項目が多いとき、選んだものをまとめて確認・整理したいときに使います。項目は [Select](../select/) と同じ `jimble-option` で書き、フォームには選択済みの値が、同じ `name` で複数送信されます。

## 操作

- **行をクリック**で選びます（もう一度クリックで解除、Shift + クリックで範囲）。「追加」で右へ、「削除」で左へ戻します。
- **行の右の ＋ / −** をクリックするか、**行をダブルクリック**すると、その 1 件だけを移します。
- 左右それぞれの検索欄で、項目名を絞り込めます（読み・全角半角・かなの違いを無視します。`jimble-option` の `keywords` に読みを書くと、それでも一致します）。絞り込みで見えなくなった項目は、選択から外れます。
- 右の一覧は、**追加した順**に並びます（`reorderable` で並べ替えられます。下を参照）。
- `move-all` で「すべて追加」「すべて削除」のボタンを出せます。`max-items` で選べる数の上限を決められます（上限に達すると「追加」が押せなくなります）。`disabled` の項目は、選べず、移せません。
- 画面が狭いときは、左右が上下の並びになり、ボタンは横並びになります。

## グループ分け（`group`）

`jimble-option` の `group` 属性に同じ名前を付けると、見出し付きでまとまります（離れて書いても、最初に現れた位置に集まります）。`group` のない項目は、そのままの位置に並びます。

- 左右どちらの一覧も、グループの見出し付きで表示されます。矢印キーは見出しを飛ばして、表示の順に進みます。
- 絞り込むと、一致する項目のないグループの見出しは消えます。**既定ではグループ名は絞り込みの対象外**です。`search-group` を付けると、グループ名でも絞り込めます。
- `reorderable` のときの右の一覧は、選んだ順に並ぶので、グループではまとめず、項目の後ろにグループ名を小さく表示します。

## 並べ替え（`reorderable`）

右の一覧（選択済み）の順番を変えられます。フォームには、その順番で送信されます。

- **ドラッグ**（マウス）: 行をドラッグします（挿入位置が線で示されます）。
- **「上へ」「下へ」ボタン**: 選んだ項目を 1 つ上 / 下へ動かします（複数選んでいれば、まとめて動きます。端では押せなくなります）。ドラッグの代わりになる、ポインター 1 本で操作できる方法です（WCAG 2.5.7）。
- **キーボード**: フォーカス中の項目を **Alt + ↑ / ↓** で動かします。
- 並べ替えると `jimble-reorder`（`detail.values` に新しい順の値）と `input` / `change` が出て、「「○○」を n 件中 m 番目に移動しました」と読み上げられます。
- 右の一覧を**絞り込んでいる間は並べ替えられません**（見えていない項目との前後が分からないため）。

## キーボード操作

| キー               | 動作                                                            |
| ------------------ | --------------------------------------------------------------- |
| ↑ / ↓ / Home / End | 項目の移動（無効は飛ばす）                                      |
| Shift + ↑ / ↓      | 選択を広げる                                                    |
| Space              | フォーカス中の項目を選ぶ / 解除する                             |
| Ctrl + A           | 見えている項目をすべて選ぶ                                      |
| Alt + ↑ / ↓        | （`reorderable` の右の一覧）フォーカス中の項目を上 / 下へ動かす |
| Enter              | 選んだ項目を移す（選んだものが無ければ、フォーカス中の 1 件）   |
| 検索欄で ↓         | リストへ移る                                                    |

移したあと、フォーカスは元のリストの次の行に残ります。移した件数は読み上げにも伝わります（`role="status"`）。

## 注意

- ラベル・ヒント・エラーは [Field](../field/) の属性で付けます。左右の見出しは `available-label` / `selected-label` で変えられます（辞書でも変えられます）。
- 項目が少なく（目安: 10 個ほど）、並べて見せる必要がなければ、[Select](../select/) や [Combobox](../combobox/)（`multiple`）のほうが場所を取りません。
- 行の右の ＋ / − は、マウスのための近道です（キーボードでは Enter と「追加」「削除」を使います）。
- 未対応: サーバーからの取得（`items` プロパティで項目を渡せます）、複数項目のドラッグでの一括移動、左の一覧の並べ替え。
