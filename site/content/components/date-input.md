`<jimble-date-input>` は、日付の入力です。テキスト欄に入力するか、カレンダーから選びます（WAI-ARIA の date picker dialog パターン）。フォームに参加し、値は `YYYY-MM-DD`（例: `2026-09-29`）の文字列で送信されます。

## 注意

- 値（`value`）は常に `YYYY-MM-DD` です。表示と入力は言語の書式（日本語は `2026/09/29`、英語は `09/29/2026`）です。ネイティブの `<input type="date">` のように、ブラウザや OS によって表示が変わることはありません。
- 入力は `2026/9/29`・`2026-09-29`・`2026年9月29日`・`20260929`・全角の数字でも受け付けます。確定（blur・Enter）すると、正規の書式に整います。
- `min` / `max`（`YYYY-MM-DD`）の外の日は、カレンダーで選べません。入力した場合は検証エラーになります。
- ラベル・ヒント（`hint`）・エラー（`error`）は [Field](../field/) の属性で付けます。カレンダーのボタンにも名前があります（辞書で変更できます）。
- 週の最初の曜日は `first-day-of-week`（0 = 日曜、1 = 月曜）で指定します。
- 時刻、期間（開始〜終了の範囲選択）、和暦、祝日の表示は未対応です。
- カレンダーは、時差の影響を受けないよう日付だけ（年・月・日）で計算します。`Date` の日付や `new Date('2026-09-29')` の結果を、そのまま渡さないでください（文字列で渡します）。

## キーボード操作

| キー（入力欄） | 動作                                       |
| -------------- | ------------------------------------------ |
| ↓              | カレンダーを開く                           |
| Enter          | 入力を確定する（フォームがあれば送信する） |

| キー（カレンダー） | 動作                                     |
| ------------------ | ---------------------------------------- |
| ← / →              | 前日 / 翌日                              |
| ↑ / ↓              | 前週 / 翌週                              |
| Home / End         | その週の最初 / 最後                      |
| PageUp / PageDown  | 前月 / 翌月（Shift を押すと前年 / 翌年） |
| Enter / Space      | 選択して閉じる                           |
| Esc                | 選ばずに閉じて、入力欄に戻る             |
