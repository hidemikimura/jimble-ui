`<jimble-date-input>` は、日付・日時・期間の入力です。テキスト欄に入力するか、カレンダー（と時刻の欄）から選びます（WAI-ARIA の date picker dialog パターン）。フォームに参加します。

| 使い方       | 属性         | 値の書式           | 例                                  |
| ------------ | ------------ | ------------------ | ----------------------------------- |
| 日付（既定） | —            | `YYYY-MM-DD`       | `2026-09-29`                        |
| 日付と時刻   | `time`       | `YYYY-MM-DDTHH:mm` | `2026-09-29T14:30`                  |
| 期間         | `range`      | `開始/終了`        | `2026-09-01/2026-09-10`             |
| 期間と時刻   | `range time` | `開始/終了`        | `2026-09-01T09:00/2026-09-10T18:30` |

## 日時（`time`）

- 日を選んだあとに、時・分の欄で時刻を入れます（24 時間表記）。時刻を入れられるよう、**カレンダーは開いたまま**で、「完了」ボタンまたは Esc で閉じます。日を選んだ直後の時刻は 00:00 です（すでに時刻が入っていれば、日を選び直しても時刻は保たれます）。
- 分の刻みは `minute-step`（既定 1）。範囲外の数値（`99` など）は 0〜23 / 0〜59 に収められます。
- 秒とタイムゾーンは扱いません（`YYYY-MM-DDTHH:mm` は、利用者の場所の時刻としてそのまま扱います。サーバーとのやり取りで時差が要るときは、アプリ側で変換してください）。

## 期間（`range`）

- 1 回目のクリックで開始日、2 回目で終了日を選びます。**開始日より前を選ぶと入れ替わります**。終了日を選ぶ前に、ホバー（またはキーボードの移動）で間の日が強調されます。開始日と終了日は、読み上げで「開始日」「終了日」と伝わります。
- 値は 開始と終了がそろったときだけ入ります（`開始/終了` の 1 つの文字列として、1 つの `name` で送信されます）。`start` / `end` プロパティで、それぞれを取り出せます。
- テキストでは `2026/09/01 〜 2026/09/10` のほか、`～`、`~`、`–`、空白つきの `-`、`to` で区切れます。終了が無い入力や、終了が開始より前の入力は、検証エラーになります。
- `range time` では、開始と終了の時刻の欄が別々に出ます。カレンダーで選んだ直後の時刻は、開始が 00:00、終了が 23:59 です（その日の全体）。
- `months="2"`（最大 3）で、複数の月を並べます。狭い画面では縦に並びます。

## 入力欄のクリックと手入力不可（`picker-only`）

- 通常の入力では、入力欄のクリックはカレンダーを開きません（文字の位置を決める操作のため）。カレンダーのボタン、または入力欄で ↓ を押すと開きます。開いたまま入力すると、解釈できた日に表示が移ります。
- `picker-only` を付けると、**手入力ができなくなり**、カレンダー（と時刻の欄）からだけ選べます。**このとき、入力欄をクリックするとカレンダーが開きます**（フォーカスは入力欄に残ります）。Space・↓ でも開き、その場合は日にフォーカスが移ります。Backspace / Delete で値を消せます。書式の誤りが起きないので、入力の検証エラー（`badInput`）もありません。`readonly`（値の変更も、カレンダーを開くこともできない）とは別です。

## 年・月の選択

カレンダーの見出しで、**月と年を直接選べます**（前の月・次の月のボタンに加えて）。遠い年月へ移るときに使います。

- 月は選択欄（言語の月の名前。日本語は `9月`、英語は `September`）、年は数値の入力欄です。年は、数字を入力して Enter（またはフォーカスを外す）か、矢印キー（↑ ↓）で変えられます。並びは言語に従います（日本語は「2026 年 9 月」、英語は「September 2026」）。
- `min` / `max` があるときは、範囲の外の月は選べず（無効）、範囲の外の年には移りません。
- `months` で複数の月を並べているときは、**最初の月**に選択欄があり、2 か月目以降は文字の見出しです。
- 選択欄・入力欄のラベルは「月」「年」です（辞書で変えられます）。PageUp / PageDown（月）、Shift + PageUp / PageDown（年）でも移動できます。

## 注意

- 値は常に上の書式で、`Date` やタイムゾーンは介しません。表示と入力は言語の書式です（日本語は `2026/09/29 14:30`、英語は `09/29/2026 14:30`）。ネイティブの `<input type="date">` のように、ブラウザや OS によって表示が変わることはありません。
- 入力は `2026/9/29`・`2026-09-29`・`2026年9月29日`・`20260929`・`14時30分`・全角の数字でも受け付けます。確定（blur・Enter）すると、正規の書式に整います。
- `min` / `max`（`YYYY-MM-DD` または `YYYY-MM-DDTHH:mm`）の外の日は、カレンダーで選べません。入力した場合は検証エラーになります。
- ラベル・ヒント（`hint`）・エラー（`error`）は [Field](../field/) の属性で付けます。カレンダーのボタンにも名前があります（辞書で変更できます）。
- 週の最初の曜日は `first-day-of-week`（0 = 日曜、1 = 月曜）で指定します。
- カレンダーは、時差の影響を受けないよう日付だけ（年・月・日）で計算します。`new Date('2026-09-29')` の結果を、そのまま渡さないでください（文字列で渡します）。
- 未対応: 秒、12 時間表記（AM/PM）、タイムゾーン、和暦、祝日の表示、特定の日の無効化、カレンダーを常に表示するインライン表示、「過去 7 日間」のような期間の候補、複数の日付を個別に選ぶ選択。

## キーボード操作

| キー（入力欄） | 動作                                       |
| -------------- | ------------------------------------------ |
| ↓              | カレンダーを開く                           |
| Enter          | 入力を確定する（フォームがあれば送信する） |

| キー（カレンダー） | 動作                                                              |
| ------------------ | ----------------------------------------------------------------- |
| ← / →              | 前日 / 翌日                                                       |
| ↑ / ↓              | 前週 / 翌週                                                       |
| Home / End         | その週の最初 / 最後                                               |
| PageUp / PageDown  | 前月 / 翌月（Shift を押すと前年 / 翌年）                          |
| Enter / Space      | 選ぶ（日付は選んで閉じる。期間は開始→終了。時刻ありは開いたまま） |
| Tab                | （時刻ありのとき）時・分の欄、「今日」「クリア」「完了」へ        |
| Esc                | 選ばずに閉じて、入力欄に戻る（選びかけの期間は捨てる）            |
