`<jimble-tooltip>` は、囲んだ要素にマウスを重ねる、またはフォーカスすると、短い補足の説明を出します。

## 属性

| 属性        | 内容                                                                                               |
| ----------- | -------------------------------------------------------------------------------------------------- |
| `text`      | 表示する文字                                                                                       |
| `placement` | 出る位置: `top`（既定）・`bottom`・`left`・`right`。画面に収まらないときは反対側に出ます           |
| `multiline` | 折り返しと改行を許可します（最大の幅 20rem）。付けなければ 1 行。改行は `&#10;` や `\n` で書きます |
| `delay`     | ポインターを重ねてから出るまでの待ち時間（ミリ秒。既定 300）。フォーカスでは待ちません             |
| `disabled`  | ツールチップを出しません                                                                           |

## 注意

- **囲む要素は、キーボードでフォーカスできるもの（ボタン・リンクなど）にしてください。** 文字だけの `span` などは、キーボードや支援技術の利用者に表示されません（開発ビルドでは警告が出ます）。
- 説明は支援技術に伝わります。ネイティブの要素（`<button>`・`<a>`）には `aria-describedby`（もとの値は残します）、`jimble-button` には `aria-description` を部品が自動で設定します。ツールチップの表示自体は読み上げから外れます。
- **囲める `jimble-*` は `jimble-button` だけです。** 入力欄など他の部品は、内側へ説明を渡さないので、キーボードの利用者にツールチップの文字が伝わりません（入力欄の説明は [Field](../field/) の `hint`）。
- WCAG 1.4.13 に沿って、**Esc で消せ**、ポインターをツールチップの上へ移しても消えず、フォーカスまたはホバーが残る間は出続けます。ダイアログの中でも、開いている間の最初の Esc はツールチップだけを消します。
- タッチ操作では、ホバーがないので、タップしてフォーカスしたときに出ます。
- **大事な情報や操作を入れないでください。** ツールチップは補足です（リンクやボタンを入れることはできません）。入力欄の説明は [Field](../field/) の `hint` を使います。
- **アイコンだけのボタンの名前は、ツールチップではなく `aria-label` で付けます**（上の例の削除ボタン）。
- 囲めるのは 1 つの要素です（先頭の要素に `aria-describedby` が付きます）。
