`<jimble-color-input>` は、色の入力です。`#rrggbb` を入力するか、色見本のボタンで開くポップアップで、色相・彩度・明度のスライダー、または候補の色から選びます。フォームに参加し、値は小文字の `#rrggbb`（例: `#4f46e5`）で送信されます。

## 注意

- 入力は `#4F46E5`・`4f46e5`・`#46e`（3 桁）・全角でも受け付け、`#4f46e5` の形に整えます。
- ネイティブの `<input type="color">` と違い、OS の色選択ではなく、ブラウザによらず同じ見た目です。
- 色見本は色だけを表すので、色を読み上げる代わりに、入力欄の 16 進数の値が名前の一部として伝わります。色だけに意味を持たせず、ラベルや文字でも区別できるようにしてください。
- 候補の色は `presets`（空白またはカンマ区切り）で差し替えられます。
- 透明度（アルファ）と、oklch など他の色空間は未対応です。
- 文字色と背景色の組み合わせのコントラストは、この部品では検査しません。

## キーボード操作

| キー（入力欄） | 動作                                       |
| -------------- | ------------------------------------------ |
| ↓              | ポップアップを開く                         |
| Enter          | 入力を確定する（フォームがあれば送信する） |

| キー（ポップアップ） | 動作                                       |
| -------------------- | ------------------------------------------ |
| Tab / Shift+Tab      | スライダー、候補の色、クリアの順に移動     |
| ← / → など           | スライダーの値を変える（ネイティブの操作） |
| Enter / Space        | （候補の色で）その色を選ぶ                 |
| Esc                  | 閉じて、入力欄に戻る                       |
