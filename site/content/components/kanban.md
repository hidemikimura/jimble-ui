`<jimble-kanban>` は、`jimble-kanban-column`（列）の中に `jimble-kanban-card`（カード）を並べたボードです。カードは、列の間や列の中を動かせます。動かすと、**カードの要素そのものが、別の列へ入れ替わります**（状態を別に持つ必要はありません）。カードの中身は、自由な HTML（見出し・バッジ・担当者など）で書きます。

## 動かし方

| 方法                                | 操作                                                                                                                                                                        |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| マウス・ペン                        | カードをドラッグします（挿入位置が線で示されます。端に近づくと自動でスクロールします）                                                                                      |
| タッチ                              | カードを**長押し**してからドラッグします（先に指を動かすと、画面のスクロールになります）                                                                                    |
| ポインター 1 本（ドラッグの代わり） | カード右上の移動ボタンを押し、出てくる「ここに移動」を押します。列の末尾にも出ます。ドラッグできない人のための方法です（WCAG 2.5.7）                                        |
| キーボード                          | カードにフォーカスして **Alt + ← / →** で隣の列へ、**Alt + ↑ / ↓** で列の中を動かします。**Space / Enter** で、移動ボタンと同じ「移動先を選ぶ」を始めます（Esc で取り消し） |

- Esc で、ドラッグも取り消せます。カード内のリンク・ボタン・入力欄の上では、ドラッグは始まりません。
- 動かしたあと、「「○○」を「△△」の n 件中 m 番目に移動しました」と読み上げられます。

## キーボード操作

| キー                | 動作                                                                        |
| ------------------- | --------------------------------------------------------------------------- |
| Tab                 | ボードの中の、カード 1 枚に入ります（そのカードの移動ボタンにも止まります） |
| ↑ / ↓               | 列の中で、前後のカードへ                                                    |
| ← / →               | 隣の（カードのある）列の、同じ位置に近いカードへ                            |
| Alt + ← / → / ↑ / ↓ | フォーカス中のカードを動かす                                                |
| Space / Enter       | 移動先を選ぶ（もう一度押すと取り消し）                                      |
| Esc                 | 移動先の選択・ドラッグを取り消す                                            |

## 動かしたときの処理

動かす直前に `jimble-card-move` が発火します（`detail`: `value`・`card`・`from`・`to`・`index`）。**キャンセル**（`event.preventDefault()`）すると、カードは動きません。サーバーへ保存して、失敗したら元のままにしたいときに使います。ボード全体の並びは、`board`（`{ 列の value: [カードの value, …] }`）で取れます。

```js
kanban.addEventListener('jimble-card-move', (e) => {
  const { value, to, index } = e.detail
  if (!canMove(value, to))
    e.preventDefault() // 動かさない
  else save(value, to, index)
})
```

## 読み取り専用・固定

- `jimble-kanban` の `readonly` で、すべてのカードを動かせなくします（閲覧用）。
- `jimble-kanban-card` の `locked` で、そのカードだけ動かせなくします（鍵のアイコンが出て、読み上げでは「移動できません」と伝わります）。
- 特定の列へ動かせないようにしたいときは、`jimble-card-move` をキャンセルします。

## 列とカード

- `jimble-kanban-column` の `heading` が見出し、件数は自動で出ます。`slot="actions"` に、見出しの右へ置く操作（「＋ 追加」ボタンなど）を入れられます。カードがないときの表示は `slot="empty"` で変えられます。
- `jimble-kanban-card` の `label` は、読み上げと通知で使うカードの名前です（省略するとカードの文字）。
- 列の幅は、CSS 変数 `--jimble-kanban-column-width`（既定 18rem）で変えます。列が多いときは、ボードが横にスクロールします。
