jimble-ui は **WCAG 2.2 AA** と **WAI-ARIA Authoring Practices（APG）** を目標にしています。

## 守っていること

| 領域             | 内容                                                                                                                                                                                                                 |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| キーボード       | すべての操作がキーボードでできます。キーの割り当ては APG のパターン（menu button、listbox、tabs、radio group、dialog など）に従い、各コンポーネントのページに表があります。                                          |
| フォーカス       | フォーカスは常に見えます（`:focus-visible`、強制色モードでは `outline`）。ダイアログ・ドロワー・メニュー・セレクトは、閉じるとフォーカスを開いた要素に戻します。固定ヘッダーの下にフォーカスが隠れません（2.4.11）。 |
| コントラスト     | 文字は 4.5:1、入力欄の枠・フォーカスリング・アイコンは 3:1 以上です（1.4.11）。既定のトークンの組み合わせを CI で検証しています。入力欄の枠が他の部品より濃いのは、このためです。                                    |
| ターゲットサイズ | 操作できる要素は、既定で 24px 以上です（2.5.8）。                                                                                                                                                                    |
| 色だけに頼らない | 種別（エラー・警告など）は文字でも伝わります（アイコン + 読み上げ用のテキスト）。                                                                                                                                    |
| 状態の通知       | alert は `role="alert"` / `"status"`、toast は通知が来る前から存在するライブリージョンで読み上げます。                                                                                                               |
| 入力の補助       | ラベル・ヒント・エラーが名前と説明として結ばれます（`jimble-field`）。`autocomplete` を通します（1.3.5）。                                                                                                           |
| 動き             | `prefers-reduced-motion` でスピナーやトランジションを止めます。                                                                                                                                                      |
| リフロー         | 320px 幅・200% ズームで横スクロールが出ません（表は、はみ出したときだけスクロール領域になり、キーボードで操作できます）。                                                                                            |
| 日本語入力       | IME の変換中の Enter / Esc / 先頭文字検索を、確定や実行として扱いません。                                                                                                                                            |

## どう確かめているか

- **自動**: すべての部品の各状態と、ドキュメントのすべての例・ページに対して、axe-core（WCAG 2.0 / 2.1 / 2.2 A・AA とベストプラクティス）を Chromium・Firefox・WebKit で実行しています。違反があるとマージできません。
- **実際のアクセシビリティツリー**: ブラウザが計算した名前・説明・ロール・状態が正しいことを、Playwright と Chromium の CDP で確認しています。
- **手動**: 自動では分からないもの（スクリーンリーダーの読み上げ、IME の実機、強制色モード、ズーム）は、リリース前に確認するチェックリストを [リポジトリ](https://github.com/hidemikimura/jimble-ui/blob/main/docs/manual-checks.md) に置いています。

自動テストは「必要条件」であって「十分条件」ではありません。アプリに組み込んだあとの読み上げの確認は、アプリ側でも行ってください。

## 利用者が気をつけること

- **ラベルを必ず付けてください。** `jimble-field`、外側の `<label for>`、`aria-label` のいずれかで、入力欄・チェックボックス・スイッチ・セレクト・アイコンだけのボタンに名前を付けます。付け忘れても警告は出ません（このリポジトリの開発ビルド・テストでは警告が出ますが、配布物には含まれません）。自分で確認してください。
- **色を変えるときは、コントラストを確かめてください。** 特に、主ボタンの背景色（白い文字が乗ります）と、入力欄の枠の色です。
- **見出しの階層は、アプリ側で整えてください。** `jimble-page-header` の `level` で合わせられます。
- **自動で消える通知に、重要な情報だけを載せないでください。** キーボードだけの人が読み終える前に消えることがあります。重要な情報は `jimble-alert` などで画面内にも表示します。
- 1 ページに `nav` の部品（パンくず・サイドバー・ページネーション）を複数置くときは、`label` で名前を変えてください。
