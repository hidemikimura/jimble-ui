---
title: 言語の切り替え
order: 3
description: 表示文言の辞書を差し替える方法
---

コンポーネントが表示する文言（「閉じる」「読み込み中」など）は日本語が既定で、辞書を差し替えると他の言語になります。足りないキーは日本語のままです。

```ts
import { setLocale } from '@hidemikimura/jimble-ui/i18n'
import en from '@hidemikimura/jimble-ui/locales/en'

setLocale(en) // 以降、すべてのコンポーネントが再描画されます
```

CDN から使う場合:

```html
<script type="module">
  import { setLocale } from '.../dist/cdn/jimble-ui.js'
  import en from '.../dist/cdn/locales/en.js'
  setLocale(en)
</script>
```

一部の文言だけを変えるには `setMessages` を使います。

```ts
import { setMessages } from '@hidemikimura/jimble-ui/i18n'
setMessages({ 'alert.dismiss': '通知を閉じる' })
```

辞書の値は `{name}` を含む文字列、または関数です（複数形など文法が複雑な言語向け）。
