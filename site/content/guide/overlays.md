ダイアログ、ドロップダウンメニュー、セレクトの一覧、通知は、ブラウザの標準機能を使って表示しています。自前で `z-index` やフォーカスの閉じ込めを実装していません。

## 使っている標準機能

| 部品                   | 標準機能                          | ブラウザが行うこと                                         |
| ---------------------- | --------------------------------- | ---------------------------------------------------------- |
| Dialog                 | `<dialog>` の `showModal()`       | 最前面への表示、背面の inert 化、フォーカスの閉じ込め、Esc |
| Dropdown Menu / Select | Popover API（`popover="auto"`）   | 最前面への表示、外側クリックと Esc で閉じる                |
| Toast                  | Popover API（`popover="manual"`） | 最前面への表示（自動では閉じない）                         |

最前面の順番は「あとから開いたものが上」です。ダイアログの中で開いたメニューは、自然にダイアログの上に出ます。

## 位置の決まり方

メニューとセレクトの一覧は、CSS Anchor Positioning でトリガーの近くに置かれ、画面に収まらないときは上下・左右に反転します。JavaScript による位置計算はありません（Chrome / Edge 125 以降、Firefox 147 以降、Safari 26 以降で動きます）。

## フォーカス

- 開くと、フォーカスは中へ移ります（ダイアログ: `autofocus` の要素または最初のフォーカス可能な要素、メニュー: 最初の項目、セレクト: 選択中の選択肢）。
- 閉じると、開く前にフォーカスしていた要素（メニューとセレクトはトリガー）に戻ります。
- ダイアログはネイティブの機能で、背面にフォーカスが出ません。メニューとセレクトは、Tab で閉じてトリガーの次の要素へ進みます。

## 閉じる操作

| 操作         | Dialog                                                                | Menu / Select        |
| ------------ | --------------------------------------------------------------------- | -------------------- |
| Esc          | `jimble-close-request` → 閉じる                                       | 閉じてトリガーに戻る |
| 外側クリック | 背景クリックで `jimble-close-request`（押下と解放の両方が背景のとき） | 閉じる               |
| 項目の選択   | —                                                                     | 実行して閉じる       |

**IME の変換中の Esc**は、変換の取り消しなので、ダイアログを閉じません。変換中の Enter や先頭文字検索も、メニュー・セレクトでは無視されます。

## 通知（Toast）とダイアログ

モーダルダイアログが開くと、その外は inert になります。外に置かれた通知は、操作も読み上げもできなくなります。そのため、通知の領域は開いているダイアログの中へ移動して表示され、閉じると `<body>` に戻ります。

## 制約

- 位置の反転はブラウザの機能に任せているため、複雑な条件（ずらして収める、最大サイズを計算するなど）は行いません。メニューと一覧は `max-height` とスクロールで収めます。
- 上記の標準機能に未対応の古いブラウザは、対象外です。
