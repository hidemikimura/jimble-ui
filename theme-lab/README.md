# theme-lab（カラーテーマ調整用のサンプルサイト）

jimble-ui で作った管理画面の見本です。デザイナーが色（CSS 変数）を変えて、管理画面全体の見た目を確かめながらテーマを作るために使います。ローカルだけで動き、外部への通信はありません。

## 起動

```bash
npm install
npm run dev
```

表示された URL（既定は http://localhost:5199 ）を開きます。

## 色を決める流れ

1. **`theme-lab/src/theme.css` を編集して保存する。** 画面がすぐ切り替わります。これが成果物です。
   - `--jimble-color-primary-*`（主色）、`neutral-*`（文字・枠・背景の灰色）、`success` / `warning` / `danger` / `info`、面・文字・枠の意味の色、角丸・影・高さが並んでいます。
   - 各行の横に、どこに使われる色かを書いています。
2. **右下の「テーマ調整」で試す。** 色を選ぶと、保存前に画面へ反映します。主色は、1 色から 50〜950 の段階を自動で作れます。「theme.css をコピー」で、調整した値を反映した `theme.css` の**全体**を書き出せます。`theme.css` の中身を、それで**置き換えます**（末尾に足さない。足すと、同じ変数が重なって、下の行だけが効きます）。ページを読み込み直すか `theme.css` を保存すると、試しの値は消えます。
3. **「コントラスト」ページで確かめる。** 文字と背景の組み合わせが基準（WCAG 2.2 AA：文字 4.5:1、枠・アイコン 3:1）を満たすかを、いまの色で計算します。「不足」が 0 件になるまで直します。

## ページ

| ページ         | 見るもの                                                             |
| -------------- | -------------------------------------------------------------------- |
| ダッシュボード | 数値カード、アラート、一覧の抜粋                                     |
| 注文の一覧     | タブ、絞り込み、並べ替えできる表、バッジ、ページ送り                 |
| 注文の詳細     | 項目の一覧、入力欄、タブ、確認ダイアログ、トースト                   |
| 入力フォーム   | すべての入力部品、必須・エラー・無効の表示                           |
| ログイン       | 枠なしの画面、エラー表示                                             |
| 部品一覧       | ボタン・バッジ・アラート・ダイアログ・ドロワーなど、状態ごとの見た目 |
| コントラスト   | 色の組み合わせの自動判定                                             |

マウスを重ねる、フォーカスする、押す、無効にする、といった**状態の色**も、「部品一覧」と「入力フォーム」で確かめてください。

## 変えられる変数は、すべて載っています

ライブラリが公開する CSS 変数は、**すべて** `theme.css` に載っていて、右下の「テーマ調整」からも、試せます（176 項目）。

- **色**（段階・面・文字・枠・区切り線・ボタン・入力欄・ツールチップ・スイッチ・表・ヘッダー・サイドバー…）
- **角丸**（全体、ボタン・入力欄・カード・バッジ・アラート・ダイアログ・メニュー・ポップアップなど、部品ごと）
- **影**（全体と、カード・入力欄・ボタン。`none` で影なし。プリセットから選べます）
- **文字**（フォント、太さ、大きさ）、**高さ・余白**、**動き**、**重なり順（z-index）**
- 部品ごとの幅・高さ・余白（ボタン、入力欄、カード、ダイアログ、かんばんの列、表のセル、左右の選択のリストなど）

調整パネルの上の検索欄で、変数を探せます（例: `shadow`・`角丸`・`ボタン`）。入力欄を空にすると、その変更を取り消します。

`theme.css` の最後の「上級」は、コメントアウトしてあります。大きさ（sm / md / lg）やボタンの種類ごとに、既定の値が違う変数で、指定すると、すべてに同じ値が効くためです。使うときは、コメントを外して、値を書いてください。

## ヘッダー・サイドバーの色

`theme.css` の「ヘッダー・サイドバー」の変数で、ヘッダーとサイドバーだけの色・アイコンの大きさを変えられます（`jimble-ui` 0.6.0 以降）。暗くするときの例が、同じ場所にコメントで入っています（背景を暗くしたら、文字・アイコン・hover・現在のページの色も一緒に変えて、「コントラスト」ページで確かめてください）。

ヘッダー左のボタンで、サイドバーを**アイコンだけの細い表示**に切り替えられます。細い表示でも、マウスを重ねる（またはキーボードで入る）と、項目名と子項目つきで広がります。状態はブラウザに覚えられます。

> このサンプルは、`jimble-ui` **0.8.0 以上**（`package.json` は `^0.8.0`）を使います。枠・区切り線・ボタンの枠の色を別々に変える、文字の太さ、カード・入力欄・ボタンの影、バッジの角丸、ツールチップ・スイッチの丸・表の見出しの色などの変数は、0.8.0 から使えます。古い版では、これらの変数は効きません。

## 書き出し

`theme.css` の `:root { … }` を、利用するアプリの CSS にそのまま貼れば、同じテーマになります。

## 開発者向け

- `npm run build` で静的ファイルを `dist` に出力します（`npm run preview` で確認）。
- ライブラリは npm の `@hidemikimura/jimble-ui` を使います。バージョンを上げるときは `package.json` を直して `npm install` します。
