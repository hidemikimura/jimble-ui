# 手動チェックリスト

自動テストでは確認できない項目。リリース前（および該当コンポーネントを変更したとき）に実施する。
結果は PR の説明か、リリースのメモに残す。

## 1. IME（日本語入力）

Playwright は本物の IME を操作できない。自動テストは `compositionstart/end` と `keydown`
（`isComposing`、`keyCode 229`）の合成イベントで、判定ロジックだけを検証している。
実機では次を確認する。

**環境**: macOS（日本語入力）× Chrome / Safari / Firefox、Windows（MS-IME）× Chrome / Edge / Firefox

**準備**: ドキュメントサイトの「フォームとの連携」ページの例（`jimble-input` が 2 つと送信ボタン）と、
入力欄が 1 つだけのフォームを用意する。

| # | 操作 | 期待 | 対象 |
| --- | --- | --- | --- |
| 1 | 「にほん」と入力し、**変換中に Enter** で確定する | 確定するだけ。フォームは送信されない | input |
| 2 | 確定後（変換中でない）に Enter | フォームが送信される | input |
| 3 | ダイアログ内の入力欄で、変換中に Esc | 変換が取り消されるだけ。**ダイアログが閉じない**（変換をやめて、もう一度 Esc で閉じる）。自動テストは Chromium の合成 IME と `cancel` イベントで確認済み | dialog + input |
| 3b | メニュー・セレクトが開いている状態で、変換中の文字入力 | 先頭文字検索が動かない | dropdown-menu / select / combobox / date-input / color-input |
| 3c | コンボボックスで「とうきょう」を変換中に ↓ / Enter | 変換の操作だけが動く。候補は選ばれない。確定後は絞り込まれ、Enter で候補を選べる | combobox |
| 3e | コンボボックス(load)で日本語を変換中 | 変換中は取得しても選択が動かない。確定後に検索語で取得される | combobox |
| 3d | 日付入力・色選択のテキスト欄で、変換中に Enter | 確定するだけ。フォームは送信されない | date-input / color-input |
| 4 | Safari: 変換確定の Enter（keyCode 229）の直後に、すぐもう一度 Enter | 1 回目は送信されない。2 回目は送信される | input |
| 5 | 変換中に矢印キー | 変換候補の選択だけが動く。ラジオの選択などが動かない | input |
| 6 | textarea で変換中に Enter | 確定するだけ。改行されない。確定後の Enter は改行 | textarea |
| 7 | 全角の数字・記号を入力（`type=number` 以外） | そのまま入力される | input |

## 4. リリース時の記録テンプレート

```md
### 手動確認（vX.Y.Z）

- 確認者 / 日付:
- スクリーンリーダー: NVDA + Firefox（ ） / VoiceOver + Safari（ ）  … 項目: 2 章の 1〜19
- IME: macOS 日本語入力（ ） / Windows MS-IME（ ）  … 項目: 1 章の 1〜7
- 表示: 200% ズーム（ ） / 320px（ ） / 強制色モード（ ） / reduced-motion（ ）  … 項目: 3 章
- 気づいたこと・未確認の理由:
```
